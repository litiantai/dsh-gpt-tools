# code-review

审查当前候选相对基线的差异，核对需求与设计版本、实际质量检查。评审独立于开发者自述。

## 审查

按 [审查依据](references/review.md) 检查正确性、兼容、错误路径、身份隔离和必要测试。提出有具体触发场景和影响的可操作问题。没有实际证据的推测标为待核实，不当作已发生失败。

## 结论

问题关联当前差异与验收条件；不能通过改测试或跳过编译批准。审查输出由平台 Schema 约束，批准不等于发布已完成。
