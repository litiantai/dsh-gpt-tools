# 实施质量

按平台测试执行模式和项目声明命令完成编译、类型检查、构建与测试。指定由本机控制器测试时，Agent 实现代码和定向用例，说明待测项目，不能自行安装依赖、启动实例或重复执行检查。Java 的编译与测试、前端的构建与测试均需要实际控制器回执；证据绑定当前源码。

内部流程缺口按原需求的 development_guidance、coordination_help_plan、acceptance 和 resolution_probes 落实：实际补齐归因回执、路线定义、请求响应留存或断言。未来字段或旧版本探针当前缺失不能成为拒绝开发的理由。每项原缺口映射能暴露它的定向回归，登记的 check 入口实际加载新增用例；固定 pass 标志、泛化绿色 suite 或开发声明不能证明效果。

Spring Boot 新增或修改类与未标注 @Override 的方法编写中文 JavaDoc，包含 @author 李天泰 <litiantai@myhexin.com> 与编写当天 @date yyyy/MM/dd（Asia/Shanghai），按需 param/return/throws；Override 可继承文档。
